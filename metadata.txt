about=Wraps the Global DEM Portal web app (https://globaldemportal.github.io) as a dockable QGIS plugin. Pick a DSM/DTM source, select tiles by click, rectangle, polygon, country search or an existing QGIS layer, and download. Tiles come from the OpenTopography public mirror (and the AWS terrain-tiles bucket for Mapzen) anonymously - no Earthdata login and no API key. Downloads are intercepted, unzipped/gunzipped as needed and added to the map as raster layers.
