about=Wraps the Global DEM Portal web app (https://globaldemportal.github.io) as a dockable QGIS plugin. Pick a DSM/DTM source, select tiles by click, rectangle, polygon, country search or an existing QGIS layer, and download. Tiles come from the OpenTopography public mirror (and the AWS terrain-tiles bucket for Mapzen) anonymously - no Earthdata login and no API key. Downloads are intercepted, unzipped/gunzipped as needed and added to the map as raster layers.

changelog=
    1.4.1
    - Basemap fix. CARTO began requiring an API key for its raster tiles, so the
      panel's map filled with tiles stamped "API KEY REQUIRED". The plugin now
      supplies a key and the map draws normally again.
    - DEM downloads are unchanged and still need no account and no API key.
    1.4
    - First release, numbered 1.4 to match the web app it mirrors. A native Qt
      panel - no web view, no local server - with nine DEM sources, Dataset
      Options split into Type (DSM or DTM) and Source, tile selection by click,
      rectangle, polygon, country search or an existing QGIS layer, and
      mosaicking with seam levelling.
